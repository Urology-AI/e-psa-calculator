Data Not Linked to You

User Content
Ask-tab chat is answered 100% on-device via Apple's on-device Foundation Models (iOS 26+, supported hardware only). No network call is made for chat and nothing is sent to us, Apple, or any third party. On unsupported devices, the app shows an "on-device AI not available" state instead of a cloud fallback. Chat history is stored locally on your device only (SwiftData) and never uploaded — so there is nothing to list here.

Data Not Collected

Contact info, precise/coarse location, financial info, contacts, photos/videos, audio, browsing history, search history, purchases, usage/analytics data, diagnostics beyond standard OS crash reporting, advertising data.
